# Files that are the same in both portals, and must stay the same.
#
# The two applications are separate on purpose - a data principal's portal and
# a staff console have different audiences, navigation and policy - but these
# files are their common ground: the API client and its errors, the key
# service walker, formatting, security helpers, UI primitives, shared types.
# 93 of them were byte-identical when this list was made (review 2026-10-01,
# ARCH-4), and a fix to one copy alone is how they drift: a security or
# accessibility fix that lands in one portal and not the other.
#
# `src/shared-files.test.ts` in each portal fails when a listed file differs
# between them. Change both copies in the same commit. To let a file diverge
# deliberately, take it off this list in that commit and say why.
#
# Moving them into one package both portals import is the better end state; it
# changes how both apps install and build, and CI, so it waits on that decision.
