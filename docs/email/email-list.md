# Every email the application sends

[Email](README.md) · [Every text](../sms/sms-list.md) · [Wording in full](messages.md)

Generated by `docs/tools/generate-message-lists.py` from the message catalogue
(`backend/api/src/cmp/core/messages.py`). Do not edit by hand; run the tool.

**97 emails. 48 may be copied (Cc); 49 never are.**

- **From**, on every email: `<organisation> Privacy Office <SENDER_EMAIL>`, one address for the whole application.
- **To**: one person per email. A message for several people is one email each.
- **Cc**: only on emails about the work between the office, staff and holders. Never on an email carrying a code or a link, or one to a person about her own data (ADR 0029).
- **Subject**: the default below, until the office replaces it in the console under **Message templates**. Words in `{braces}` are filled in when it is sent.
- The console sends and manages all of them. The portal sends none itself; it is where the links in them open.

## Where email stands, and the plan

### Already built

| Piece | State |
|---|---|
| One sending path (`deliver()`), after the transaction commits, retried by the worker | Built |
| HTML layout: one header, one footer, code box, button, headings; plain-text copy in the same email | Built (`infrastructure/email/layout.py`) |
| From: `<organisation> Privacy Office <SENDER_EMAIL>` | Built; the name is fixed in code |
| Cc per email, set by the office in Message templates (up to 5) | Built |
| Cc for the whole deployment, `EMAIL_CC_ADDRESSES` (up to 5) | Built; empty on this machine |
| Subject and body edited by the office, with a preview | Built (console, Message templates) |
| Test mode, `EMAIL_REDIRECT_TO` | Built |
| Real delivery over SMTP (465, 587 or 25) | Built; not switched on here: `SMTP_SERVER` is empty, so email goes to the local outbox file |

### To switch on From and Cc (settings only, no code)

In `backend/api/.env`, then restart the API and the worker:

```
SMTP_SERVER=<mail server>
SMTP_PORT=587
SMTP_USERNAME=<login>
SMTP_PASSWORD=<password>
SENDER_EMAIL=<the real From address>
EMAIL_CC_ADDRESSES=<up to five, comma-separated>
```
