# DKMS — encryption of personal data

Everything about the key service and what it protects, in four documents.
Personal data is **encrypted before it reaches the database** and
**decrypted only in the frontend layer**: the platform API stores and serves
ciphertext, and a portal opens a value at the moment a person reads it.
