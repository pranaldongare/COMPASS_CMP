<a id="breach-ticket-access"></a>
## 4. Temporary console access for a breach ticket

Key `breach_ticket_access` · channels: email

| | |
|---|---|
| When | Sent to somebody with no console login whom the Privacy Office - or a colleague - has asked to answer a ticket (S3-09). It gives temporary access to the console to answer it - when the matter is closed they can still read it, no longer answer it - and how to set a password. It names no breach (BD-18). Email only; sent by the sign-in service, like an invitation. |
| To | Somebody with no console login asked to answer a breach ticket, at the work email given. |
| CC | Never - it carries a code or a link, and a copy would hand it to somebody else. |
| Attachment | None. |
| Sent by | `cmp.notifications.send_breach_ticket_access` (`backend/api/src/cmp/tasks/notifications/staff.py:68`) |
| Queued from | `backend/api/src/cmp/auth/authentication/service.py:567` |
| Variables | `full_name` (The person given access.), `code` (The six-digit one-time code.), `hours` (How many hours the code is valid for.), `reset_url` (The console page where they set their password, with their address filled in.), `organisation` (The organisation's name (ORGANISATION_NAME).) |

**Subject:** `The {organisation} Privacy Office has asked for your help`

**Body:**

```text
{full_name}, the {organisation} Privacy Office has given you temporary access to its console to answer a ticket. When the matter is closed you can still read the ticket, but no longer answer it.

Set your password here:
{reset_url}

and enter this code on that page:

    {code}

The code works once and expires in {hours} hours. If it has expired, choose "Forgotten your password?" on the sign-in page and a new one will be sent to this address. Afterwards you sign in with your password and a six-digit code sent here each time. What the ticket is about is in the console only.

If you were not expecting this message, please tell the Privacy Office at {organisation}.
```
